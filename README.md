# Sunan Ibn Majah - Digital Hadith Library

A professional, feature-rich Hadith application focused on the Sunan Ibn Majah collection. Built with Flutter for a seamless experience on Android and beyond. Developed by **Taha imam**.

## ✨ Key Features

- **Full Collection**: Entire Sunan Ibn Majah database.
- **Multi-lingual Support**: Read Hadiths in Arabic, Urdu, and English.
- **Advanced Search**: Find specific Hadiths or topics instantly.
- **Custom Collections**: Create and manage your own groups of Hadiths.
- **Rich Typography**: Optimized fonts for Arabic (Lateef, Scheherazade) and Urdu (Jameel Noori Nastaleeq).
- **Offline Access**: Use the app anywhere without an internet connection.
- **Immersive Design**: Modern UI with dark mode and customizable themes.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (3.19.0 or higher)
- Android Studio / VS Code
- Dart SDK

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/tahaimam/sunan-ibn-majah-app.git
   ```
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
